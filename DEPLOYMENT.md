# Deployment Guide

This project is a Laravel 12 app with Vite assets, database queue workers, and external Meta integrations.

## 1) Server Requirements

- PHP 8.2+ with common Laravel extensions (`mbstring`, `openssl`, `pdo`, `tokenizer`, `xml`, `ctype`, `json`, `bcmath`, `fileinfo`)
- Composer 2+
- Node.js 20+ and npm
- MySQL 8+ (or compatible)
- A process manager for queue workers (Supervisor/systemd)
- Nginx or Apache

## 2) Environment Setup

Create `.env` on the server (do not copy local secrets blindly):

- Core
  - `APP_ENV=production`
  - `APP_DEBUG=false`
  - `APP_URL=https://your-domain.com`
  - `APP_KEY=...` (generate once with `php artisan key:generate`)
- Database
  - `DB_*` values for production
- Session / cache / queue
  - This app defaults to DB-backed drivers (`SESSION_DRIVER=database`, `CACHE_STORE=database`, `QUEUE_CONNECTION=database`)
- Mail
  - Set your SMTP/provider values
- Integrations (required if using those channels)
  - WhatsApp: `FACEBOOK_APP_ID`, `FACEBOOK_APP_SECRET`, `WHATSAPP_*`
  - Messenger: `MESSENGER_*`

## 3) First-Time Deployment

Run from project root:

```bash
composer install --no-dev --prefer-dist --optimize-autoloader
npm ci
npm run build
php artisan key:generate
php artisan migrate --force
php artisan storage:link --force
php artisan config:cache
php artisan route:cache
php artisan view:cache
```

If needed, warm queues/session/cache tables:

```bash
php artisan queue:table && php artisan migrate --force
php artisan session:table && php artisan migrate --force
php artisan cache:table && php artisan migrate --force
```

## 4) Subsequent Deployments

Recommended release flow:

```bash
git pull
composer install --no-dev --prefer-dist --optimize-autoloader
npm ci
npm run build
php artisan down
composer run deploy
php artisan up
```

`composer run deploy` runs:

- `php artisan migrate --force`
- `php artisan storage:link --force`
- `php artisan config:cache`
- `php artisan route:cache`
- `php artisan view:cache`

If you need to clear all caches quickly:

```bash
composer run deploy:clear
```

## 5) Required Background Processes

### Queue worker (required)

Use Supervisor/systemd to keep this running:

```bash
php artisan queue:work --sleep=1 --tries=3 --timeout=120
```

Restart workers after each deployment:

```bash
php artisan queue:restart
```

### Scheduler (recommended)

Set one cron entry:

```bash
* * * * * cd /path/to/project && php artisan schedule:run >> /dev/null 2>&1
```

## 6) Web Server Notes

- Point web root to `public/`
- Ensure writable permissions for:
  - `storage/`
  - `bootstrap/cache/`
- Serve `public/build` assets generated by Vite

## 7) Quick Health Checks After Deploy

- Open `/login` and `/dashboard`
- Verify `php artisan migrate:status`
- Verify queue is processing jobs (`queue:work` logs)
- Confirm webhooks and integration callbacks use the production `APP_URL`
- Check `storage/logs/laravel.log` for errors
